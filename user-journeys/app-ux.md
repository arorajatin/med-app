Overall UX is divided into the following tabs

Feed | Chat | Upload | Drive | Profile

- Feed has a chronological feed of all the uploaded items (could be pulled in from upload tab, WhatsApp, email etc)
- Chat is a chatbot to chat with the memory and documents, along with the information available.
- Upload is a simple screen with the capability to upload medical documents in forms of images or PDFs, and add a description with the document (if any)
- Drive is a folder view (similar to Google Drive), the folders are created using tags associated with the uploaded documents
- Profile screen will have email details, image thumbnail, family tree, major conditions per family member, medicines per family member
